GCC build (arm-none-eabi-gcc)
=============================

Projekt sa da buildovat bez Keilu cez root Makefile.

Prerequisites:
- arm-none-eabi-gcc
- arm-none-eabi-objcopy
- arm-none-eabi-size
- make

Podporene aplikacie:
- test_button
- test_RS485
- test_RS485_modbus
- test_onewire
- test_ir_tx
- test_ir_rx
- test_ds18b20
- test_rf433

Zakladne spravanie:
- `make` -> default build pre RAM
- `make r` -> build RAM
- `make f` -> build FLASH
- `TARGET_BUILD` moze byt iba `RAM` alebo `FLASH`

Globalne definicie podla variantu:
- RAM: `STM32F10X_MD`, `VECT_TAB_SRAM`
- FLASH: `STM32F10X_MD`

Vystupy:
- RAM: `build/<APP>_ram/<APP>.elf|hex|bin`
- FLASH: `build/<APP>_flash/<APP>.elf|hex|bin`

Priklady build prikazov z root priecinka:
- `make APP=test_button`
- `make APP=test_RS485 r`
- `make APP=test_RS485 f`
- `make APP=test_RS485 TARGET_BUILD=RAM`
- `make APP=test_RS485 TARGET_BUILD=FLASH`

Clean:
- `make clean` -> maze iba aktivny variant (podla `TARGET_BUILD`, default RAM)
- `make clean_r` -> maze iba `build/<APP>_ram`
- `make clean_f` -> maze iba `build/<APP>_flash`
- `make clean_all` -> maze cely `build`

Build z priecinka aplikacie:
- z `apps/test_button`: `make`, `make r`, `make f`, `make clean_r`, `make clean_f`
- wrapper Makefile automaticky zavola root Makefile s korektnym `APP`
