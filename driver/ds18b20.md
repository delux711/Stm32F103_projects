# ds18b20

Driver pre meranie teploty zo senzora DS18B20.
Komunikacia je realizovana cez existujuci 1-Wire driver `onewire`.

## Subory
- `ds18b20.h` - verejne API
- `ds18b20.c` - implementacia DS18B20 operacii nad 1-Wire

## Zapojenie

Priklad (STM32F103, pin PB7):

```
PB7  <-> DQ (DS18B20)
3.3V <-> VDD
GND  <-> GND
```

Na DQ je potrebny externy pull-up rezistor 4.7 kOhm na 3.3V.

## API

### `DS18B20_init`
Inicializuje DS18B20 driver a interne zavola `OW_init`.

### `DS18B20_startConversion`
Odosle prikaz `CONVERT T (0x44)`.

### `DS18B20_readScratchpad`
Precita 9 bajtov scratchpadu (`READ SCRATCHPAD`, 0xBE)
a overi CRC.

### `DS18B20_readTemperatureC10`
Vrati teplotu v desatinach stupna C (0.1 deg C).

### `DS18B20_discoverSingle`
Najde jedno zariadenie na zbernici cez ROM search.

## Pouzitie

```c
static const DS18B20_config_t ds_cfg = {
    .ow = {
        .port = GPIOB,
        .pin = 7u,
        .cpu_freq_hz = 72000000u
    },
    .use_rom_match = 0u
};

DS18B20_init(&ds_cfg);

DS18B20_startConversion();
SYS_delayMs(750u);

int16_t temp_c10;
if (DS18B20_readTemperatureC10(&temp_c10) == DS18B20_OK) {
    // temp_c10 = 253 znamena 25.3 deg C
}
```

## Poznamky
- Pri 12-bit rozliseni trva konverzia az 750 ms.
- `use_rom_match = 0` pouzi `SKIP ROM` (vhodne pre jedno zariadenie).
- Pre viac zariadeni nastav `use_rom_match = 1` a vypln `rom`.
