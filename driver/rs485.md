# rs485

Ovládač pre RS-485 komunikáciu cez USARTx so smerovaním RX/TX cez DIR pin.

## Súbory
- `rs485.h` – verejné API, konfiguračná štruktúra
- `rs485.c` – implementácia

## Konfigurácia

Celé nastavenie sa odovzdáva cez štruktúru `RS485_config_t`:

```c
typedef struct
{
    GPIO_TypeDef *txPort;          // port TX pinu
    uint8_t       txPin;           // pin TX
    GPIO_TypeDef *rxPort;          // port RX pinu
    uint8_t       rxPin;           // pin RX
    GPIO_TypeDef *dirPort;         // port DIR pinu (TX enable)
    uint8_t       dirPin;          // pin DIR
    uint32_t      usartRemapMask;  // maska pre AFIO_MAPR
    uint32_t      usartRemap;      // hodnota remapu (0 = žiadny remap)
    USART_TypeDef *usart;          // USART1 / USART2 / USART3
    IRQn_Type     usartIrqn;       // IRQ číslo USART
    volatile uint32_t *usartRccReg; // napr. &RCC->APB2ENR
    uint32_t      usartRccBit;     // napr. RCC_APB2ENR_USART1EN
    uint32_t      baudrate;        // napr. 9600
} RS485_config_t;
```

## API

### `RS485_init`
```c
void RS485_init(const RS485_config_t *config);
```
Inicializuje GPIO (TX, RX, DIR), USART a povolí prerušenie. Štartuje v RX smere.

---

### `RS485_setRxCallback`
```c
void RS485_setRxCallback(RS485_rxCallback_t rx_callback);
```
Registruje callback volaný z USART IRQ pri každom prijatom bajte.

```c
typedef void (*RS485_rxCallback_t)(uint8_t data);
```

---

### `RS485_send`
```c
void RS485_send(const uint8_t *data, uint16_t length);
```
Prepne smer na TX, odošle blokujúco `length` bajtov, potom prepne späť na RX.

---

### `RS485_goToMuteMode`
```c
void RS485_goToMuteMode(void);
```
Prepne USART do Mute módu (ignoruje príjem, kým nepríde adresový bajt).

---

### `RS485_usartIrqHandler`
```c
void RS485_usartIrqHandler(void);
```
Volať z `USARTx_IRQHandler` v `bsp_irq.c`.

## Príklad zapojenia v `bsp_irq.c`

```c
void USART1_IRQHandler(void) {
    RS485_usartIrqHandler();
}
```

## Použitie

```c
static const RS485_config_t rs485_cfg = {
    .txPort        = GPIOB,
    .txPin         = 6u,
    .rxPort        = GPIOB,
    .rxPin         = 7u,
    .dirPort       = GPIOB,
    .dirPin        = 8u,
    .usartRemapMask = AFIO_MAPR_USART1_REMAP,
    .usartRemap     = AFIO_MAPR_USART1_REMAP,
    .usart          = USART1,
    .usartIrqn      = USART1_IRQn,
    .usartRccReg    = &RCC->APB2ENR,
    .usartRccBit    = RCC_APB2ENR_USART1EN,
    .baudrate       = 9600u
};

RS485_init(&rs485_cfg);
RS485_setRxCallback(myRxHandler);

uint8_t msg[] = "Hello\r\n";
RS485_send(msg, sizeof(msg) - 1u);
```

## Poznámky
- DIR pin sa prepína HIGH pred odoslaním a LOW po odoslaní (DE logika pre RS-485 transceiver).
- Parita je voliteľná – odkomentovať `#define RS485_PARITY_ENABLE` v `rs485.c`.
