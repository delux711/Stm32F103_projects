# rf433

Driver pre RF433 MHz modul (prijímač/vysielač).

Modul je pripojený na UART bez riadiaceho signálu (na rozdiel od RS485, ktorý má DE/RE pin).
Rámce sú v rovnakom formáte ako MODBUS RTU (slave_addr + function + data + CRC16).

## Súbory
- `rf433.h` - verejné API
- `rf433.c` - implementácia

## Hardware (LS-RX433 / LS-TX433)

Typický UART modul na 433 MHz:

```
LS-RX433/TX433 VCC     -> 3.3V (alebo 5V podľa modulu)
LS-RX433/TX433 GND     -> GND
LS-RX433/TX433 TX/RX   -> UART RX
LS-RX433/TX433 RX/TX   -> UART TX
```

Na komunikáciu sa používa UART bez HW flow control.

## Konfigurácia

```c
static const RF433_config_t rf433_cfg = {
    .txPort         = GPIOA,
    .txPin          = 9u,
    .rxPort         = GPIOA,
    .rxPin          = 10u,
    .usartRemapMask = AFIO_MAPR_USART1_REMAP,
    .usartRemap     = 0u,          // no remap
    .usart          = USART1,
    .usartIrqn      = USART1_IRQn,
    .usartRccReg    = (volatile uint32_t *)&RCC->APB2ENR,
    .usartRccBit    = RCC_APB2ENR_USART1EN,
    .baudrate       = 2400u        // RF433 moduly: 2400, 4800, 9600 baudov
};
```

## API

### `RF433_init`
```c
void RF433_init(const RF433_config_t *config);
```
Inicializuje UART a GPIO.

### `RF433_setRxCallback`
```c
void RF433_setRxCallback(RF433_rxCallback_t rx_callback);
```
Nastaví callback pre príjem bytov. Callback sa volá z UART IRQ.

### `RF433_send`
```c
void RF433_send(const uint8_t *data, uint16_t length);
```
Odošle pole bytov cez UART (do RF modulu TX).

### `RF433_usartIrqHandler`
```c
void RF433_usartIrqHandler(void);
```
UART IRQ handler - volá sa z `bsp_irq.c`.

## Príklad použitia - MODBUS RTU cez RF433

```c
// RF433 frame handler (podobne ako MODBUS_RTU_onRxByte)
static void APP_rf433RxByte(uint8_t byte)
{
    // Zbiera bajty do bufferu, spúšťa dekódovanie
}

// Inicializácia
RF433_init(&rf433_cfg);
RF433_setRxCallback(APP_rf433RxByte);

// Odoslanie rámca (s CRC16)
uint8_t frame[10] = {0x01, 0x03, ...};  // slave_addr, function, data...
uint16_t crc = CRC16(frame, 8);
frame[8] = (uint8_t)(crc & 0xFF);
frame[9] = (uint8_t)((crc >> 8) & 0xFF);
RF433_send(frame, 10);
```

## Poznámky

- RF433 moduly majú ľahší bitrate - typicky 2400–9600 baudov
- Bez HW flow control (iba TX/RX)
- Vzdialenosť: do 100 m v otvore, cez steny menej
- Frekvenčný rozsah: 433 MHz (ISM pásmo)
- Musí sa rešpektovať legislatíva krajiny (limitácia výkonu, duty cycle)
